# Resume task routing

Before every resume task or follow-up edit, run `git branch --show-current` and read the active checkout's `instructions.md`, `README.md` command, and `plugins/resume-creator-plugin/skills/resume-creator/SKILL.md`.

The current user command and active branch determine the domain, source profile, header, and employment designation. Earlier conversation preferences apply only within their original branch/domain scope. Re-read these instructions after a branch switch; do not carry AWS SRE titles into Azure DevOps resumes.

Follow the required branch and request check in `instructions.md`, including pre-render and pre-delivery checks. On this Azure branch, the header is `Lead Azure DevOps Engineer | AI | K8s` and the latest AT&T designation is `Lead Azure DevOps Engineer`.
